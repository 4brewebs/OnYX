## [Unreleased]

### Security (`open-onyx` — `openonyx serve` Hardening: Strict HTTP Parser, Login Rate Limiting & `Host`/TLS-Proxy/CORS Controls)

- **Strict HTTP request parser (`open-onyx/src/web.rs`, `open-onyx/src/main.rs`)**: a strict line-bounded request parser with a fixed per-line cap applied before authentication, CRLF-only line endings, rejection of duplicated or unknown headers (e.g. double `Content-Length` → `400`), and explicit `431 Request Header Fields Too Large` / `413 Request Entity Too Large` for oversized headers/body (FIX-08, FIX-11, FIX-12, FIX-41).
- **Connection & resource hardening (`open-onyx/src/web.rs`)**: a per-connection read deadline plus a parked-connection cap (accept-loop `peek`, bounded thread pool) so slow or idle unauthenticated clients cannot pin threads or file descriptors, and an injected spawner that closes only the failing connection on a `spawn` error instead of killing the acceptor (FIX-09, FIX-35).
- **Session, auth & CSRF hardening (`open-onyx/src/web.rs`)**: a bounded server-side session table (`__Host-`/`Secure` cookies, 256-bit tokens) with logout revocation, a trivalent Bearer token (invalid → `401`, no cookie fallback), a `Sec-Fetch-Site` + `Origin` CSRF guard (a cross-site POST with cookie → `403`), and `Content-Type: application/json` enforced for cookie POSTs (`415`) (FIX-10, FIX-37, FIX-42, FIX-94).
- **Login rate limiting (FIX-14)**: per-IP and global attempt caps (at least 5 per IP, at least 20 global per 60 s) applied before the key is checked, returning `429 Too Many Requests` + `Retry-After`.
- **`Host` validation & TLS-proxy mode (FIX-16, FIX-17, FIX-36)**: opt-in `--allowed-hosts a,b` allowlist (a missing or foreign `Host` → `421 Misdirected Request`) and `--behind-tls` to declare a TLS-terminating reverse proxy — enabling exposed/secure mode (HSTS, `__Host-`/`Secure` cookies, `https` links) computed as `!is_loopback() || --behind-tls` and never from a client-controlled `X-Forwarded-Proto`.
- **SSE transport correctness (FIX-66, FIX-67)**: `X-Accel-Buffering: no` on the SSE response and a keep-alive ping delivered as a named `event: ping` so proxies do not buffer and clients can detect a dead stream.

### Added (`open-onyx` — Configurable LLM Provider HTTP Timeouts (FIX-02))

- **Configurable LLM connect/read timeouts (`open-onyx/src/{llm_profile.rs, main.rs, openai.rs, anthropic.rs, gemini.rs}`)**: added `--llm-timeout-connect <secs>` (default `30`) and `--llm-timeout-read <secs>` (default `120`) with `ONYX_LLM_TIMEOUT_CONNECT_SECS` / `ONYX_LLM_TIMEOUT_READ_SECS` fallbacks, applied per-request to all three providers via `ureq` `timeout_connect`/`timeout_read`. A provider that accepts the connection and then goes silent now fails the turn in bounded time with a classified transport error instead of hanging the session (e.g. `serve`) forever; read timeouts are **not** retried (to avoid duplicate inference), while connect failures and `408`/`429`/`5xx` remain retried with backoff; `0` = unset.

### Added (`open-onyx` — SDD-07: `TimeFreeze` Interactive Time Debugger — shared engine, sealed 0-token primitives, TUI & Web parity)

- **Shared time-debug engine (`open-onyx/src/time_debug.rs`, commits `b2a68a6`, `e6c8441`)**: `TimeDebugState` — `frozen` / `cursor_tick` / `present_tick` over a RAM tick-boundary ring (bounded, eviction-safe) overlaid with on-disk `SharedPackStore` milestone references — with `preview_graph(cursor)` projection cache (the files that would be reverted on branch, computed 0 I/O from the live side-effect ledger), a mutation gate that keeps the graph 100 % frozen while `frozen`, and `confirm_branch_from_cursor` (Git tree checkpoint restore from `tree_sha` + pack fork + ring truncation). - **TimeFreeze in the TUI (`open-onyx/src/{tui.rs, tui_views.rs, tui_palette.rs, main.rs}`, commit `14690a2`)**: amber `⏸ TIME FROZEN · tick X / present Y` banner with the would-be-reverted files (RAM-only), `Alt+←` / `Alt+→` scrubbing over the available tick ring (looking at the past auto-freezes), `Ctrl+T` freeze toggle, safe `Esc` returning to the present **without quitting** while frozen, `F5 Timeline` scrubbing with `[pack:*]` / `[ram]` / `(present)` labels and a `▶ cursor` marker, and the 7 time-debug slash commands in the `/` autocomplete and the `Ctrl+K` palette.
